# 🎮 Telegram-бот «Steam-скидки» — автономный клон формата @steam_ss

Бот **сам** ищет все скидки Steam, генерирует премиальные карточки и публикует посты по расписанию. Работает 24/7 без вашего ПК.

## Что умеет

- 🔍 **Ищет ВСЕ скидки Steam** (`search?specials=1`, ~17 000 игр). Проверка каталога — каждые `SYNC_HOURS` часов (по умолчанию **4** = 6 раз в сутки) + быстрая подкачка, если очередь кандидатов пустеет. **Никакого отсева игр**: в пуле остаются все игры со скидками; вес (отзывы + скидка) влияет только на порядок очереди, чтобы известные игры выходили раньше.
- 💰 **Все валюты всегда**: 🇷🇺 ₽ (со старой ценой) · 🇰🇿 ₸ · 🇺🇦 ₴ · 🇺🇸 $. Если игра заблокирована в РФ — цена считается по курсу ЦБ РФ (`cbr-xml-daily.ru`, раз в сутки + кэш + фолбэк): сконвертированная цена пишется с тильдой — `🇷🇺 ~3 195 ₽`. Никакой «бухгалтерии» в тексте: ни «Стоимость по регионам», ни «Выгода», ни «по курсу ₸».
- 🇷🇺 **Описание — одно чистое предложение** (до 130 символов) из русского описания Steam. Нет законченного русского предложения — абзац не выводится вовсе (никакого машинного перевода). Локализация: `Полная русская озвучка 🎙` / `Русские субтитры 💬` / `Без перевода 🌐`.
- 🖼 **Карточки** 1280×720 (JPEG q95, суперсэмплинг ×2): одиночная (`make_card`) и мульти-сетка 2–4 игр (`make_multi_card`) — на каждой ячейке крупная цена в ₽ и строка `5 250₸ · 389₴ · $19.99`.
- ✍️ **9 рубрик:** `single`, `multi`, `series`, `roundup`, `ending`, `under300` (хиты дешевле 300 ₽), `freebie` (скидка 100% — сразу после sync), **`releases`** (новинки и релизы Steam — 1 раз в день, ~85% канала остаётся про скидки), **`event`** (тематическая подборка активного сезона).
- 🎃 **Календарь событий (`events.py`):** Хэллоуин (20.10–05.11), осенняя (24.11–04.12), зимняя (15.12–10.01), весенняя (13–20.03) и летняя (25.06–11.07) распродажи. В сезон на карточках скидок — праздничная плашка («ХЭЛЛОУИН В STEAM»), тематические игры (по названию/жанрам/описанию) поднимаются в начало очереди — **без отсева**, только порядок.
- 🛠 **Автоочистка диска:** после каждой публикации удаляются её рабочие картинки (`raw_*`, `card_*`), полная уборка `images/` — не чаще раза в сутки (`maybe_cleanup`). Аватарки и тестовые файлы не трогаются.
- 🩺 **Самодиагностика:** `python run_bot.py --selfcheck` или команда `/check` — SQLite/WAL и число игр, шрифты, генерация карточки в памяти, курсы валют, активный сезон, права бота в канале, свободное место на диске.
- 🎛 **Inline-кнопки под каждым постом:** `single` — «🛒 Открыть в Steam» + «📊 История цен (SteamDB)»; групповые — сетка кнопок по 2 в ряд с названием и скидкой каждой игры.
- ✨ **Эмодзи-слоты:** все эмодзи постов настраиваются в личке бота (`/emojis`, `/setemoji fire 🔥`, `/resetemojis`) и хранятся в SQLite — переживают перезапуск. Можно ставить премиум-эмодзи (сохраняется `custom_emoji_id`); команда `/emoji_id` возвращает id пересланного эмодзи. Отправка каскадом: полный HTML → без `tg-emoji` → без `blockquote/code` → plain — пост не теряется никогда.
- 🛡 **Модерация комментариев:** детектор по токенам с границами слов и белым списком (никаких ложных мутов на «тебе», «ребята», «мудрый», «рисунок», «парикмахер»). Страйки в SQLite → муты 15 мин / 2 ч / 24 ч, удаление сообщения, уведомление с автоудалением через 30 сек. Самотест: `python moderator.py --selftest`.
- 🔒 **Безопасность:** маскировка `BOT_TOKEN` в логах, `html.escape()` всех Steam/пользовательских строк, картинки только с https-доменов Steam (≤10 МБ, чанками), параметризованный SQL + WAL, `USER appuser` в Dockerfile, админ-команды заблокированы при `OWNER_ID=0`.

## 🚀 Быстрый старт (локально)

```bash
python -m venv .venv
.venv\Scripts\activate           # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env           # заполни BOT_TOKEN, CHANNEL, OWNER_ID
python run_bot.py
```

Первый запуск автоматически скачает шрифты (Montserrat / Noto Sans) в `assets/fonts/`.

## ☁️ Автономный деплой 24/7 (без вашего ПК)

### Вариант А — Docker (VPS / Railway / Render / Fly.io)

```bash
docker compose up -d --build
docker compose logs -f
```

`docker-compose.yml` с `restart: unless-stopped` и volume для `./data` — база не теряется при перезапусках. Контейнер работает от непривилегированного `appuser`.

### Вариант Б — GitHub Actions (бесплатный serverless-крон)

1. Залить проект в GitHub-репозиторий (`.env` не коммитить).
2. **Settings → Secrets and variables → Actions**: `BOT_TOKEN`, `CHANNEL`, `CHANNEL_TITLE`, `OWNER_ID`.
3. Workflow `.github/workflows/autopost.yml` — запуск каждые 3 часа + кнопка Run workflow (ручной запуск дополнительно прогоняет `--selfcheck`).

Механика: `python run_bot.py --once` → раз в сутки уборка `images/` → sync при необходимости → пост по текущему слоту (окно 3.5 ч, защита от дублей через SQLite) → выход. Кэшируются `data/state.db`, `data/rates.json` и `assets/fonts/`.

## ⚙️ Ключи `.env`

| Ключ | Значение |
|---|---|
| `BOT_TOKEN`, `CHANNEL`, `CHANNEL_TITLE` | бот и канал |
| `OWNER_ID` | ваш Telegram ID; **пока 0 — админ-команды заблокированы** |
| `DISCUSS_CHAT_ID` | чат обсуждений (0 = авто по типу чата) |
| `SYNC_HOURS` | период синхронизации каталога (по умолчанию 4) |
| `MIN_DISCOUNT` | минимальная скидка, % (по умолчанию 15) |
| `MIN_SCORE` | вес для **порядка** очереди; 0 = в пуле все игры |
| `PREMIUM_EMOJI` | 1/0 — использовать `<tg-emoji>` |
| `CUSTOM_EMOJI_MAP` | свои emoji-id: `fire=5368…,gem=5312…` |
| `CAPTION_LIMIT` | лимит подписи (Telegram max 1024) |
| `SCHEDULE` | `10:00 roundup, 12:00 releases, 13:00 single, 15:00 under300, 18:00 multi, 20:00 ending, 22:00 single` |

## 🗂 Структура

```
config.py        конфиг из .env (SYNC_HOURS, PREMIUM_EMOJI, CUSTOM_EMOJI_MAP, MIN_SCORE)
currency.py      курсы ЦБ РФ раз в сутки + фолбэк + конвертация в ₽
events.py        календарь праздников/распродаж Steam + тематические ключевые слова
fonts.py         автоскачивание шрифтов Montserrat/Noto
images.py        make_card + make_multi_card (все валюты на карточках, плашки рубрик)
steam.py         Steam API: скидки, цены ru/kz/ua/us, отзывы, локализация, новинки/релизы
templates.py     текст постов, эмодзи-слоты (SQLite), 9 рубрик, лимиты Telegram
poster.py        оркестратор: sync → формат → карточка → отправка + фолбэки + очистка диска
moderator.py     модерация: мат/оскорбления/спам, страйки, временные муты
avatars.py       аватарки канала и саппорта (python avatars.py)
security.py      маскировка BOT_TOKEN в логах
run_bot.py       24/7 демон | --once (cron) | --force <kind> | --selfcheck
```

## ⚙️ Команды бота (только владельцу)

```
/status       — статистика, активный сезон и расписание
/check        — самодиагностика автономности (7 проверок)
/sync         — обновить каталог скидок
/post single|multi|series|roundup|ending|under300|freebie|releases|event
              (так же: /post halloween|autumn|winter|spring|summer)
/emojis       — какие эмодзи стоят в каждом слоте
/setemoji fire 🔥 — запомнить эмодзи для слота (можно premium — сохранится id)
/resetemojis  — вернуть набор по умолчанию
/emoji_id     — переслать сообщение с premium-эмодзи → получить custom_emoji_id
```

```bash
python run_bot.py --force multi      # принудительный пост
python run_bot.py --selfcheck        # самодиагностика (код 1 при проблемах)
python moderator.py --selftest       # проверка детектора мата (0 ложных срабатываний)
python avatars.py                    # перегенерировать аватарки
```

## 📝 Заметки

- Steam ограничивает запросы — между вызовами пауза `STEAM_DELAY`; детали игры кэшируются в памяти на 30 мин.
- Флаги, иконки и скругления рисуются **векторно** (ImageDraw), без эмодзи в тексте — карточка идентична на Windows/Linux/Docker.
- «Рекордная скидка» = эвристика `≥70%` (честный all-time-low требует истории цен).
- Не коммитьте `.env` — там реальный `BOT_TOKEN`.
